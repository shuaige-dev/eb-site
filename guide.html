① 它能做什么

「硬邦邦的香蕉」是一款装在 Photoshop 里的 AI 修图插件,把顶尖的 AI 图像生成能力直接接进你的工作流。两大核心功能:

🎨 AI 创成式填充 —— 框选画面里的任意区域,用一句话描述你想要的改动,AI 就帮你重绘。换衣服、改颜色、加饰品、去杂物、改表情……都行。抠好的透明背景图也完美支持。

🖼️ AI 扩图(向外扩展) —— 把画布往外拉大,AI 自动补全空白区域,原图像素 100% 保留、自动对齐、颜色无缝衔接。半身照扩成全身、补全被裁掉的背景,一键搞定。

② 安装

系统要求:Windows + Photoshop 24.2 或更新版本,联网。

准备工作

先下载 ZXP/UXP Installer 工具（用来把插件装进 Photoshop）：

→ 点此下载 ZXP/UXP Installer

同时在 PS 里开启开发者模式：编辑 → 首选项 → 增效工具 → 勾选「启用开发人员模式」，然后关闭 PS。

安装步骤

  1. 双击 ErectBanana-x.x.x-License.exe，按默认选项一路 Next → Install 完成安装。
    安装路径默认为 C:\Users\你的用户名\AppData\Local\Erect Banana
  2. 安装完成后，找到安装目录里的 plugin.ccx 文件：
    • 有 Adobe CC 的用户：会自动弹出安装窗口，直接确认即可。
    • 没有 CC 的用户：打开 ZXP/UXP Installer，点 File → Open，找到 plugin.ccx 安装。
  3. 重启 Photoshop。
  4. 顶部菜单 增效工具(Plug-ins)→ 硬邦邦的香蕉，打开插件面板即可使用。
提示:安装包已自动配置好后台服务并设为开机自启，正常情况下你无需任何额外操作，打开 PS 就能用。

③ 首次配置(填 API Key)

插件通过 AI 服务 API Key 来生成图像。第一次使用，在面板顶部的 API Key 输入框里粘贴你的 Key 即可（支持右键直接粘贴）。

  • 插件会自动识别你的 Key 属于哪个平台，并切换到对应的可用模型。
  • 支持的平台会以彩色标识显示：🔵 AI Studio 🟢 Vertex AI 🟣 麦包 API
  • 填好后可点 测试连通性 确认是否正常。
  • Key 会被记住，并提供历史下拉，换 Key 时直接选，不用重复输入。

去哪里获取 API Key？

支持以下三个平台，选一个申请即可：

平台地址说明
Google AI Studio（推荐）aistudio.google.com免费额度，支持 Gemini 全系列
ChatGPT 官方platform.openai.com支持 GPT-Image-2
麦包 API（国内方便）api.maibao.chatGemini + GPT 都支持，充值方便
小贴士：国内用户如果访问 Google 有困难，推荐使用麦包 API，或配合住宅 IP 工具：IPRoyal。

④ AI 创成式填充

用来重绘画面里的某一块——换衣服、改颜色、加/去物体等。

操作步骤

  1. 在 Photoshop 里用选区工具(套索、快速选择等)圈出你想改动的区域。
    建议沿物体边缘做精准轮廓选区,效果最好。
  2. 在插件的 提示词 框里,用一句话描述你要的效果,例如:「把衣服改成背心」、「换成红色」、「去掉背景里的路人」。
  3. 选好模型(默认 Gemini 3.1,见第 ⑥ 节)。
  4. 点击香蕉按钮(填充),或直接按 Enter。
  5. 稍等片刻,结果会自动作为新图层精准置入原位置,显示「✓ 完成!结果已精准置入」。
透明抠图也支持:对抠好的透明背景图做填充时,如果 AI 去掉了一部分(比如把 T 恤改成背心、去掉了袖子),那部分会自动变透明、边缘干净、无白边,不会留下白底残块。

⑤ AI 扩图(向外扩展)

用来把画面往外补全——半身扩全身、补背景、改画幅比例。

操作步骤

  1. 用 裁剪工具 或 图像 › 画布大小,把画布往需要扩展的方向拉大,让原图周围出现透明空白区。
  2. 点击插件的 扩图 按钮。
  3. AI 会补全空白区域,原图部分原封不动保留,结果自动置入新图层。
扩全身小技巧:扩人物时,下方多留一些高度,AI 才能按真实人体比例把腿、脚补完整;留得太矮容易把比例压缩。
关于背景图层:如果提示「当前是背景图层(锁定状态)」,双击图层缩略图把它转成普通图层后再试。

⑥ 模型怎么选

面板里的 模型 下拉会根据你的 Key 自动列出可用项。常用建议:

模型特点 / 适用
Gemini 3.1 Flash Image(默认)综合最佳,扩图对齐最准,速度快。日常首选。
Gemini 2.5 Flash Image更快更省,质量略低,适合批量。
Gemini 3 Pro Image质量更高,耗时更长,用于精修。
GPT-Image-2另一套画风,适合局部填充改写。

扩图遇到对不齐时,优先用 Gemini 3.1;它对结构续接的对齐效果最好。

⑦ 实用技巧

  • Enter = 直接开始填充,不用去点按钮。
  • API Key 框支持右键粘贴;并有历史记忆下拉。
  • 可导入参考图,让生成结果参考你给的风格/物体。
  • 提示词越具体,结果越可控;一次不满意可以多生成几次取最好的。
  • 右上角齿轮进入设置(语言等)。

⑧ 常见问题

提示连接失败 / 用不了

插件需要配套的后台服务运行(安装时已设为开机自启)。如遇此提示,重启 Photoshop;仍不行就重启电脑让后台服务自动拉起,再打开 PS。

提示「没有找到选区」

填充前必须先在画面上做一个选区。请用选区工具圈出要改的区域再点填充。

生成失败 / 一直显示忙

多为网络或服务繁忙。稍等几秒重试;确认 API Key 有效、账户额度充足、网络(含代理)正常。

扩图接缝对不齐

切换到 Gemini 3.1 模型;扩展方向多留些空白;复杂人体结构建议分次小幅扩展。

改了设置 / 更新后没反应

重启 Photoshop 让插件重新加载即可。

透明图填充后边缘有问题

请确认源图确实是透明背景(抠好的图)。本插件会自动处理透明边缘,正常情况下袖口/裁切处会干净透空。
