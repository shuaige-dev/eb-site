① 系统要求

项目要求
操作系统Windows 10 / 11（64位）
Photoshop 版本24.2 或更新版本
网络需要联网（调用 AI 接口）
API Key需要自备 Gemini 或 GPT API Key

② 安装程序

1运行安装向导
双击下载的 ErectBanana-x.x.x.exe，出现安装向导，点 Next 继续。
2选择安装路径
默认路径 C:\Users\你的用户名\AppData\Local\Erect Banana，直接点 Next。

路径里的 Sg 是截图中的用户名，你的会显示为你自己的用户名。
3点击 Install 安装
确认路径无误，点 Install 开始安装。安装完成后有 Adobe CC 的用户会自动弹出插件安装弹窗，确认即可，跳到第 ④ 节。

没有 CC 的用户继续下一步。

③ 安装插件到 Photoshop（无 CC 用户）

需要先下载免费工具 ZXP/UXP Installer：aescripts.com/learn/zxp-installer →
4打开 ZXP/UXP Installer
打开工具，看到如右图界面。点顶部菜单 File → Open（或直接把文件拖进来）。
5找到 plugin.ccx
在弹出的文件选择窗口里，找到路径：
C:\Users\你的用户名\AppData\Local\Erect Banana\

选中 plugin.ccx，点打开。
6安装成功
看到 Erect Banana 出现在列表中并显示版本号，说明插件已成功安装进 Photoshop。
⚠️ 弹出 aescripts 登录窗口？直接关掉即可，不需要登录账号也能完成安装。
⚠️ 如果通过 ZXP/UXP Installer 安装后插件仍未出现，请手动安装：
  1. 找到安装目录里的 plugin.ccx 文件，把后缀改为 .zip，然后解压。
  2. 把解压出来的整个文件夹重命名为 ErectBanana。
  3. 将 ErectBanana 文件夹复制到：
    C:\Program Files\Adobe\Adobe Photoshop 202x\Plug-ins\
    （202x 对应你的 PS 版本号，如 2024、2025、2026）
  4. 重启 Photoshop，从增效工具菜单打开插件。

④ Photoshop 配置

7打开增效工具首选项
在 PS 顶部菜单点：
编辑 → 首选项 → 增效工具
8勾选「启用开发人员模式」
在增效工具页勾选 启用开发人员模式，点确定后关闭并重启 Photoshop。
9从菜单打开插件
重启 PS 后，点顶部菜单：
增效工具 → Erect Banana → 硬邦邦的香蕉

插件面板出现，安装完成 🎉

⑤ 获取 API Key

插件需要 API Key 才能调用 AI 生成图像。支持以下三个平台，选一个申请即可：

平台地址说明
Google AI Studio（推荐）aistudio.google.com免费额度，支持 Gemini 全系列
ChatGPT 官方platform.openai.com支持 GPT-Image-2，需付费充值
麦包 API（国内方便）api.maibao.chatGemini + GPT 都支持，国内充值方便
国内用户提示：访问 Google AI Studio 需要梯子。推荐直接使用麦包 API，国内直连，支持全部模型。
住宅 IP 工具推荐：IPRoyal

拿到 Key 后，粘贴到插件面板顶部的 API Key 输入框（支持右键粘贴），插件自动识别平台并切换模型列表。

⑥ 激活许可证

插件提供免费试用期，试用期内无需激活可直接使用。购买后：

  1. 收到 License Key（邮件或站内信）。
  2. 在插件面板的激活框里粘贴 Key，点 激活。
  3. 一个 Key 最多绑定 3 台设备，换设备遇到问题请联系我们。
