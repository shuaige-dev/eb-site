What it does
Generative Fill

Change anything with a selection and a prompt.

Draw a selection around any area, describe the change you want, and the result is composited directly into a new layer — with automatic feathered-mask blending. Works on transparent cutout images too.

How to install

Erect Banana is distributed through Adobe Exchange. The plugin itself installs in one click; the local processing engine needs a separate one-time download.

1
Install the plugin from Adobe Exchange Search "Erect Banana" in Photoshop's Exchange panel, or open the listing page directly.
2
Download and run the Companion Engine The plugin needs a small local service to process images. Download ErectBanana-1.0.0-Exchange.exe and run it once — it will start automatically with Photoshop from then on.
3
Open Photoshop → Plugins → Erect Banana Paste your API key from any supported provider and click Test Connection to verify.
4
Make a selection and start generating Draw a selection, type a prompt, click the banana button — or press Enter.
